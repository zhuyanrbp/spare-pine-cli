# spare-pine-cli

Turning complex problems into a lightweight and simple software solutions.

处理日常小任务的工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/spare-pine-cli.git
cd spare-pine-cli
cargo build --release
```
